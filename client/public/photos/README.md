# Club photos

Drop photos from the club's Instagram (or phone) into this folder and the
landing page picks them up automatically. Use these exact file names:

| File | Where it appears | Good choice |
|---|---|---|
| `hero.jpg` | Behind the big title at the top | A wide court/action shot |
| `community.jpg` | Next to "Our story" | A group photo, portrait orientation |

Missing photos are fine — the page falls back to brand-green panels.
After adding files here, commit them (`git add`, `git commit`) like any change.
