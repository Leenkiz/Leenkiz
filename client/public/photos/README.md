# Club photos

The landing page uses these files. Replace any of them with a new photo of
the same name and it updates automatically.

| File | Where it appears | Shape |
|---|---|---|
| `hero.jpg` | Top of the page (under the title on phones, behind it on computers) | Landscape, group on court |
| `community.jpg` | Under "Our story" | Landscape, group photo |
| `coaching-drills.jpg` | "What you'll find here", left | Portrait, coaching / drills |
| `coaching-juniors.jpg` | "What you'll find here", right | Portrait, coaching |

Keep photos small for mobile data: about 1600px wide for `hero.jpg`, 900–1400px
for the others, saved as JPG. Only use photos where everyone shown is happy to
be on a public website (for under-18s, with a parent's OK).

A missing photo falls back to a brand-green panel.
